# Arclume Runtime notices

The initial Arclume Runtime build tooling was extracted and adapted from the
Arclume/Procyon+ codebase on 2026-08-20. Its GPLv3 license text is retained in
`LICENSE.txt`; the implementation-specific changes are documented in this
repository.

Wine itself is not committed as a worktree here. The locked public
CodeWeavers FOSS source archive is downloaded by `script/sync-wine-source.sh`.
Keep all Wine, CodeWeavers, and component notices when distributing a built
runtime to anyone outside this private development repository.
