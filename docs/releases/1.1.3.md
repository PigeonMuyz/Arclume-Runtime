# Arclume Wine 1.1.3

- 加入 GStreamer 1.28.7、FFmpeg 7.1.5 和 dav1d 1.5.3，启用 Wine 的 GStreamer / FFmpeg 媒体桥接。
- 扩展常见视频、音频与封装格式的软件解码；修复 AV1 已解码却不输出画面的问题，补齐 MJPEG 解析。
- 保留 1.1.2 的 Dock 图标留白、加载锁及 FineWine 兼容补丁；GLib / Wine 不依赖旧系统缺失的 pipe2。
- Runtime ABI 1、Prefix ABI `arclume-jx3-prefix-1` 不变，现有容器无需迁移或重装游戏。需要回退时使用 1.1.2。

**已知问题：YY 在麦序模式下可能仍出现交互无响应。** 不保证所有频道模式及长期语音会话稳定。

## 构建与验证

此归档由维护者本机从锁定源码和补丁构建，不是 GitHub Actions 产物。macOS 宿主为 x86_64（AMD64），Windows 模块保留 i386 / x86_64 WoW64。

- 正式归档解压后：FFmpeg / GStreamer 双路径命令行解码 **32 项通过，0 失败，0 跳过**。
- 构建、缓存、打包、发布门禁及源码附件回归 **52 项通过**；Runtime preflight 和差异检查通过。
- **139 个原生文件**通过 x86_64 架构与签名检查；Wine loader 保留麦克风输入 entitlement。
- 使用 **Apple Development 签名，未做 Developer ID 公证**。

视频测试覆盖 H.264、HEVC、VP8、VP9、AV1、MPEG-2/4、MJPEG、WMV1；音频覆盖 AAC、MP3、Vorbis、Opus、FLAC、PCM、AC-3、E-AC-3、WMA1/2、ALAC。另含常见封装及 MP4 音视频双流测试，均要求实际输出解码数据。

测试机为 Apple Silicon / macOS 27。**未在 macOS 26 实机或游戏内部播放链路上完成验收**，不承诺全部格式、DRM 或硬件解码。此次发布不替换本机 App、已安装运行时或游戏容器，也不更新 App 内置下载清单。

媒体新增依赖及 Wine 桥接模块的路径检查通过。基线 GnuTLS 仍保留一条旧构建目录的 RPATH（不属于新增媒体依赖）；本次未改动该基线加载配置。
