# Arclume Wine 1.1.4

- 接入 FineWine 的 msync 线程退出修复：不再把共享内存 alert 索引当作 Unix 文件描述符关闭。
- FineWine Wine 补丁固定到 `eb11be4a4bf2bb1ab27374f3bcfa408426297b32`，共 24 个。只适用于 Arclume Runtime，不修改 Nefinita，也不引入 CrossOver App 修补。
- 保留 GStreamer 1.28.7、FFmpeg 7.1.5、dav1d 1.5.3，以及现有 Dock 图标留白和加载锁修复。
- Runtime ABI 1、Prefix ABI `arclume-jx3-prefix-1` 不变，已有容器无需迁移或重新安装游戏。回退时使用已发布 1.1.3；不要删除游戏容器。

**已知问题：YY 在麦序模式下仍可能无响应。** 此版本不保证所有频道模式和长时间语音会话稳定。

## 构建与验证

由维护者本机从锁定源码重新编译，不是 GitHub Actions 产物。macOS 宿主为 x86_64（AMD64），Windows 模块保留 i386 / x86_64 WoW64。

- 构建、缓存、打包、发布门禁及源码附件回归 52 项通过。
- Runtime preflight 与 Dock 图标比例回归通过。
- 正式归档解压后的 FFmpeg / GStreamer 双路径解码：32 项通过，0 失败，0 跳过；覆盖常见视频、音频、封装及双流输出，不访问音视频设备。
- 139 个原生文件通过 x86_64 架构与严格签名检查。
- 采用与 1.1.3 相同的 Apple Development 签名身份，Wine loader 保留麦克风输入 entitlement；不是 Developer ID 公证版本。
- 测试机为 Apple Silicon / macOS 27。未完成 macOS 26 实机、实际游戏视频播放和长时间频道测试。
