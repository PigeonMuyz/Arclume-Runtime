# Arclume Wine 1.1.2

- Wine Dock 图标按可见边界等比例缩小，保留透明轮廓，已有留白不重复缩小。
- 修复内置窗口类注册与 loader lock 的锁顺序；成套更新 32 / 64 位 Windows 组件，macOS 宿主仍为 AMD64。
- Runtime ABI 与 Prefix ABI 不变，不迁移或删除用户容器。需要回退时使用此前的 1.1.1 Runtime。

**已知问题：YY 在麦序模式下可能仍出现交互无响应。** 不保证所有频道模式及长期语音会话稳定。

## 构建与验证

此归档由维护者本机从本版本锁定源码和补丁构建，不是 GitHub Actions 产物。32 / 64 位加载锁隔离回归、Dock 图标算法六类用例及签名校验通过；YY 普通模式依据用户反馈未复现卡住。

使用 Apple Development 签名并保留 Wine 麦克风输入 entitlement，未做 Developer ID 公证。
