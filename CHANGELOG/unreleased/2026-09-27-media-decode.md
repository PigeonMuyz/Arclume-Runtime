# 多媒体解码候选构建

- 新增独立的 x86_64 GStreamer / FFmpeg 构建链和固定来源校验，保留 AV1 软件解码支持。
- Wine 同时启用 winegstreamer 与 winedmo 的 FFmpeg 支持；依赖缺失时构建失败，不再静默产出缺少解码能力的版本。
- 新增无画面、无声音的命令行样本解码测试及隔离插件注册表。
- 修复 gst-libav 的 libdav1d 输出帧标记，补齐 MJPEG 解析；为旧系统保留 GLib 的 pipe / fcntl 路径。
- 候选归档与清单采用不覆盖的事务式输出；Wine 缓存绑定完整构建配置，发布前必须通过候选包解码矩阵，失败与跳过均不放行。
- 本次只生成 `1.1.3-dev.1` 本地候选，不更新 App Manifest、不上传 OSS、不发布、不替换用户运行时。
- Runtime ABI / Prefix ABI 保持不变；不读取或迁移游戏容器。回滚使用原有 1.1.2，解码插件随候选运行时整体隔离。
- 游戏内部 Media Foundation / DirectShow 的最终兼容性仍需单独验证，插件数量不代表所有游戏视频可用。
- 本地候选实际验收：32 项归档内解码全部通过、48 项回归通过、102 个原生文件通过架构/依赖/签名检查。详见 `docs/media-validation-2026-09-27.md`；未执行游戏或用户容器，未在 macOS 26 上实测。
