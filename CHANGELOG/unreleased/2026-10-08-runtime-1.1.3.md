# 发布 Arclume Wine 1.1.3

- 将已通过命令行验收的多媒体候选提升为 stable 1.1.3，加入 GStreamer 1.28.7、FFmpeg 7.1.5 和 dav1d 1.5.3。
- 保留 1.1.2 的 Dock 留白、加载锁及 FineWine 补丁；修复 AV1 输出帧与 MJPEG 解析，并保留旧系统 pipe / fcntl 回退。
- 发布归档、SHA-256 清单、逐项解码报告和对应源码材料；发布说明准确区分 Apple Development 签名与 Developer ID 公证。
- Runtime ABI 1、Prefix ABI arclume-jx3-prefix-1 不变，不迁移、重置或覆盖用户容器；回退使用 1.1.2。
- 本次仅发布独立 Runtime，不修改 App 清单、OSS 组件目录或 /Applications。游戏内播放和 macOS 26 实机验收未完成；YY 麦序模式可能仍会无响应。
