# 发布 Arclume Wine 1.1.4

- 重新编译带 FineWine msync 线程退出修复的 Wine 11，保持 1.1.3 媒体配方与 Runtime / Prefix ABI。
- 沿用 1.1.3 构建时的本地 1.1.2 打包基线，重新叠加新编译的 Wine 与锁定媒体 SDK，避免重复媒体文件冲突；生成独立归档、绑定 SHA-256 的 Manifest、对应源码和解码报告，不覆盖旧版制品。
- 只更新 Arclume Runtime；Nefinita 不变。App 通过固定清单下载新版本，不直接替换用户已安装运行时或容器。
- GitHub Actions 发布说明从锁文件读取补丁数量和来源，避免写死旧补丁集。
- 验证、签名类型、未验证范围与回退方法详见 docs/releases/1.1.4.md。
