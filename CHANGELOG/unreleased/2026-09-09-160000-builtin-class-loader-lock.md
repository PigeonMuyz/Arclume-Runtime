# 内置窗口类初始化加载锁实验补丁

- 将内置窗口类的一次性初始化移动到 user32 回调，在加载锁下完成 win32u 类注册、默认布局和主题加载，避免光标加载与 DllMain 注册窗口类的锁顺序反转。
- 新私有 NtUserCallNoParam 编号仅追加；必须同时部署 i386/x86_64 user32.dll 和 win32u.so，不能单独替换其中一个。既有编号和 WOW64 回调编号不变。
- 新增独立并发夹具和临时容器测试入口。旧 1.1.1 在强制交错下 32/64 位均挂起；实验版两种位数均通过并能创建 Button 控件。
- 仅构建独立测试产物；不修改 runtime.env、正式 Manifest、dist 归档、已安装 Runtime 或游戏设置。YY 频道、声音、反复启动和其他应用的回归尚未完成，不应发布。
- 补丁放在不会自动应用的 experimental 目录；构建后还原共享源码中的本次试验改动，避免常规单架构构建意外混入新私有接口。
- 撤回实验时停止独立测试进程，使用原安装版本重新启动；不要将两个版本的组件混用。源码补丁可反向应用，用户容器无需清理。
