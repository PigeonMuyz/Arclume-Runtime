# YY 加载锁顺序修复与已知限制

- user32 在内置窗口类初始化前获取可重入 loader lock，消除 DllMain 注册窗口类和 pthread_once 之间的锁序反转。
- 双 PE 架构构建，成套更新 i386 / x86_64 user32 与 Unix win32u。新增私有调用编号只追加；用户 Prefix ABI 不变。
- 此前实验已通过 32／64 位隔离死锁夹具。需要对本次完整产物重新运行夹具，不能把旧产物测试视作新产物验证。
- **YY 在麦序模式下可能仍出现交互无响应。** 本补丁不宣称完整解决所有频道问题，保留原有 DNS 与软件频道渲染适配。
- 回滚使用已验证的 1.1.1 整包，不混用单个 DLL，不更改用户容器或 YY 文件。
